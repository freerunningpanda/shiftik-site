Шифтик PRO — бессрочное право пользоваться дополнительными функциями приложения «Шифтик», установленного из RuStore (простая неисключительная лицензия), для личных нужд на своих устройствах. На дату этой редакции в PRO входят:

Состав PRO показан на экране PRO в приложении до оплаты. Функции, которые были бесплатными, когда покупатель начал пользоваться приложением, остаются бесплатными. Покупка в версии из RuStore не переносится в версию из Google Play: там PRO покупается через Google Play.

Сразу после оплаты. Приложение получает с сервера продавца ключ PRO, проверяет его и включает PRO; после этого для PRO интернет не нужен. На новом телефоне PRO восстанавливается кнопкой «Восстановить по коду» или из файла резервной копии, сделанного после покупки. Храните код покупки и не публикуйте его: по нему PRO может включить любой. Если код потерян, напишите продавцу дату и сумму оплаты — продавец постарается найти покупку.
